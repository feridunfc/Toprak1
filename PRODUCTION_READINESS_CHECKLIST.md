# Toprak1 / IRONCLAD - Production Readiness Checklist

## Current readiness level

Current level: **local/dev evidence-ready**

Toprak1 is not yet production-ready. The audit and dashboard evidence tooling are usable, but runtime production readiness still requires replay, persistence, operational, and staging hardening.

## Authority and audit

- [x] Banned authority findings are at zero.
- [x] Suspicious findings are classified.
- [x] Static false positives are separated from risk score.
- [x] Observability-only writes are reduced to low-risk telemetry.
- [x] Lua projection writes are separated from Lua authority transitions.
- [x] Scheduler fallback writes are classified for review.
- [x] Authority audit can emit dashboard JSON artifact output.
- [x] CI must upload/preserve authority dashboard artifacts.
- [ ] CI must enforce banned findings as a hard gate.
- [x] CI must expose risk score and class counts in artifacts.

## Dashboard

- [x] Local read-only dashboard exists.
- [x] Authority, replay, quarantine, artifact, event, and worker panels exist at MVP level.
- [x] Generated dashboard JSON artifacts are ignored by git.
- [x] Dashboard must reliably prefer latest CI artifact when available for authority and replay evidence.
- [ ] Dashboard must show artifact source and timestamp.
- [ ] Dashboard must have degraded Redis/offline mode clearly visible.
- [ ] Dashboard must remain read-only by invariant tests.
- [ ] Dashboard must not expose write, approval, retry, or mutation actions.

## Runtime correctness

- [x] Redis/Lua task lifecycle has atomic dispatch/claim/complete/requeue foundations.
- [x] Tenant isolation, rate limiting, fairness, reservation, and fencing patterns exist.
- [ ] Replay compare must become a release gate. Sprint 12 completed replay evidence artifact reporting; hard mismatch gating is planned for Sprint 13.
- [ ] Cold restart and in-flight recovery semantics must be proven.
- [ ] Archive and replay semantics must be documented and tested.
- [ ] Worker lifecycle under Redis failover/network partition must be hardened.
- [ ] Scheduler fallback invariants must be reviewed.

## Cognitive path

- [ ] CognitiveExecutor contract must be frozen against BaseExecutor.
- [ ] Semantic pipeline contracts must be canonical.
- [ ] FeedbackWriter needs hard bounds, cooldown, and HITL gate.
- [ ] Graph truth validation must be implemented or explicitly stubbed.
- [ ] Full cognitive path must pass staging-like integration tests.

## Repo hygiene

- [x] `CURRENT_STATE.md` exists.
- [x] `PRODUCTION_READINESS_CHECKLIST.md` exists.
- [ ] Historical sprint/final/patch reports must be archived or indexed.
- [ ] Duplicate readiness reports must be consolidated.
- [ ] Package install strategy must be normalized.
- [ ] Docker/K8s deployment docs must be current.

## Release gate

Production-like readiness requires:

- [ ] Banned findings remain zero.
- [ ] Risk-bearing suspicious findings reduced with evidence.
- [ ] Full test suite green.
- [ ] Replay gate green.
- [ ] Dashboard artifact generated by CI.
- [ ] 24-hour staging soak test completed.
- [ ] Operational runbook and alerting documented.

- [x] Replay compare script can emit `latest_replay.json`.
- [x] CI generates replay evidence artifact in reporting mode.
- [x] Dashboard replay read model loads replay artifact when present.
- [x] Dashboard replay read model reports invalid replay artifact read-only.
- [x] Dashboard replay read model falls back to readiness when replay artifact is absent.
- [ ] Replay mismatch hard gate is enabled in CI.
