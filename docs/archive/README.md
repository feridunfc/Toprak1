# Archive Policy

This directory is reserved for historical sprint reports, patch reports, deployment notes, and superseded readiness documents.

Do not delete historical reports during active hardening work unless they are known duplicates. Prefer moving superseded documents here and referencing the current source of truth:

- `CURRENT_STATE.md`
- `PRODUCTION_READINESS_CHECKLIST.md`
- `docs/dashboard/dashboard-architecture.md`
- `docs/ops/suspicious_risk_classification.md`

Archive policy:

1. Current truth lives in top-level current-state/readiness docs.
2. Historical sprint notes may be archived here.
3. Generated artifacts do not belong here.
4. Do not move code, tests, schemas, or operational scripts into archive.
